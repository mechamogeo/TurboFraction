# TurboFraction — downloads

Extensão do Chrome para o Fraction Web (Jadlog).

## Instalar
1. Baixe **[turbofraction.zip](https://github.com/rameno-hash/TurboFraction-update/raw/main/turbofraction.zip)** e descompacte.
2. Abra `chrome://extensions`, ative o **Modo do desenvolvedor** e clique em **Carregar sem compactação**.
3. Escolha a pasta `turbofraction` (a que tem o `manifest.json`).

## Atualizar
Quando sair uma versão nova, aparece uma faixa vermelha no Fraction e a palavra **NOVA** no ícone da extensão.
1. Baixe o `turbofraction.zip` e descompacte **no lugar** da pasta antiga (substituindo os arquivos).
2. Em `chrome://extensions`, clique no ↻ da TurboFraction.
3. Recarregue o Fraction (F5).

A versão mais recente está em [`versao.json`](versao.json). O histórico de cada versão está em [`CHANGELOG.md`](CHANGELOG.md).
