# Política de Privacidade — TurboFraction

Última atualização: 29/10/2026

A TurboFraction é uma extensão do Google Chrome que adiciona recursos de produtividade ao sistema Fraction Web, usado pelas unidades operacionais da Jadlog. Ela só funciona para quem já tem login no Fraction Web e usa apenas os dados que esse usuário já pode ver no sistema.

## Quais dados a extensão usa

Para funcionar, a extensão lê informações exibidas nas páginas do Fraction Web, por exemplo:
- números de remessas, listas de entrega e notas fiscais;
- status, ocorrências e datas das remessas;
- nome, endereço e telefone do destinatário, que aparecem na consulta da remessa;
- códigos lidos pelo leitor de código de barras nas telas de Recebimento e Lista de Entrega.

## Onde os dados ficam

- **No próprio computador.** Tudo é processado no navegador do usuário. A extensão guarda no armazenamento local do Chrome apenas o necessário: os códigos lidos (para o usuário salvar ou reenviar), o arquivo da Performance de Entrega (para não gerar de novo até a próxima atualização do Fraction) e preferências de tela.
- **Nada é enviado ao desenvolvedor.** A extensão não tem servidor próprio, não coleta estatísticas de uso, não usa cookies de rastreamento e não vende nem compartilha dados com terceiros.

## Quando dados saem do computador

Só por ação do usuário e só para estes destinos:
- **Fraction Web (jadlog.com.br):** os mesmos pedidos que o usuário faria clicando nas telas do sistema.
- **Meu Danfe (meudanfe.com.br):** ao clicar em "DANFE ↗", a chave de acesso da NF-e é informada nesse site para exibir o documento.
- **Google Maps e WhatsApp:** ao clicar nos ícones de mapa ou de WhatsApp, o endereço ou o telefone do destinatário é aberto nesses serviços.

## Permissões

- **storage / unlimitedStorage:** guardar localmente os códigos lidos, preferências e o arquivo da Performance de Entrega.
- **webRequest:** observar (sem alterar) um redirecionamento do próprio Fraction Web na tela de Consulta, para abri-la corretamente em https.
- **alarms:** verificação periódica de versão nas instalações feitas fora da Chrome Web Store.
- **Acesso a jadlog.com.br/FractionWeb:** a extensão só atua nas páginas do Fraction Web (e na página do Meu Danfe aberta pelo usuário).
